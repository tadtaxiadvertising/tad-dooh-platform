## Variant: Calm Editorial

### Design Stance
Elegant serif wordmark with subtle accent line — editorial warmth meets professional restraint. Playfair Display brings authority and sophistication; DM Sans keeps it grounded and readable.

### Key Choices
- **Layout:** Centered, generous whitespace, single-column stack
- **Typography:** Playfair Display (serif, display) + DM Sans (sans, UI)
- **Color:** Deep ink (#1a1a2e) + muted slate + muted blue accent
- **Interaction:** Clickable variant tabs (1-3 keys), keyboard accessible, dark mode native

### Trade-offs
- **Strong at:** Hero usage, personal sites, portfolios, speaking decks, print
- **Weak at:** Tiny favicon sizes (serif details lost), high-density UI toolbars

### Best For
Personal brands wanting warmth, credibility, and a "writer/thinker" feel. Works beautifully large — the accent line scales elegantly.
