## Variant: Utilitarian Dense

### Design Stance
Technical, precise, developer-native. Space Grotesk + JetBrains Mono — fonts built for code and UI density. Cyan accent signals technical competence. Four weight/width variants cover every use case from favicon to hero.

### Key Choices
- **Layout:** Centered, compact, high information density
- **Typography:** Space Grotesk (geometric grotesk) + JetBrains Mono (technical monospace)
- **Color:** Pure dark/light modes, cyan accent (#22d3ee), zinc neutrals
- **Interaction:** Clickable variant cards with hover elevation, keyboard accessible (1-4 keys)

### Trade-offs
- **Strong at:** Dev tools, GitHub profile, CLI branding, technical speaking, favicons, dense UIs
- **Weak at:** Warmth, editorial contexts, luxury/premium positioning

### Best For
Developer personal brands, technical consultants, open source maintainers, engineers who want "this person writes code" signal immediately.
