`TextMorph.tsx` derives from [text-morph.tsx](https://github.com/ibelick/motion-primitives/blob/120f64f6ca60348e251f929e9c81f11ccbe45eda/components/core/text-morph.tsx), upstream commit `120f64f6ca60348e251f929e9c81f11ccbe45eda`, source blob `f8ea5f7f9b5b65f66ec3e8373553b1923a910e2f`. License checked 2026-11-02, America/La_Paz, at the [same commit](https://github.com/ibelick/motion-primitives/blob/120f64f6ca60348e251f929e9c81f11ccbe45eda/LICENCE.md).

TAD adaptation uses the installed Framer Motion runtime, a span-only interface, static SSR/reduced/unknown-preference rendering, accessible text and a finite transition. It preserves the occurrence-based character identity and layout transition. No second Motion package is installed. Browser and bundle acceptance belong to the current implementation checkpoint.
