## Variant: Balanced Geometric

### Design Stance
One variable font (DM Sans) does it all — weight, width, and optical size axes create four distinct personalities from a single file. Warm terracotta accent adds humanity without sacrificing professionalism. Light/dark mode native.

### Key Choices
- **Layout:** Centered, balanced rhythm, card-based variant picker
- **Typography:** DM Sans variable font (opsz, wdth, wght axes) — single font file, infinite variants
- **Color:** Cream/charcoal base (not pure white/black), terracotta accent (#c45a3d), slate muted
- **Interaction:** Elevated variant cards with warm hover shadows, keyboard accessible (1-4 keys)

### Trade-offs
- **Strong at:** Versatile across all platforms, single font load, modern but approachable, prints beautifully
- **Weak at:** Extreme differentiation between variants (they're intentionally related)

### Best For
Personal brands needing one logo system that works everywhere: LinkedIn avatar, website hero, slide deck, business card, email signature. The variable font means zero font-loading complexity.
